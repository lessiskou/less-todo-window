# 任务编辑弹层 + 底部圆角残影修复 — 设计

日期：2026-11-25

## 意图

双击任务编辑时，当前是一个单行 `<input>`，长文本只能看到一小段，编辑时难以确认全文。
把它换成窗内弹层 + 多行编辑，并让窗口在编辑期间临时增高，关掉后恢复。

同时修复底部圆角外的"透明方角"：实测是卡片外层 `box-shadow` 落在圆角外的三角形区域，
被窗口矩形直边硬裁，留下半透明残影（窗口隐藏/显示对比：该区域 alpha 16~42；去掉外层投影后为 0）。
现行设计里这块投影在直线边缘本来就无处可见，去掉后观感几乎不变。

## 目标

- 双击任务文字打开编辑弹层：半透明遮罩 + 面板，覆盖整张小窗。
- 多行文本框完整显示原文、自动换行；短文本面板紧凑，长文本约 12 行后文本框内部滚动。
- 编辑期间窗口高度临时增加（复用现有 `setContentHeight`，仍受屏高 45% 上限约束），关闭后恢复。
- 键盘/鼠标：`Enter` 保存、`Shift+Enter` 换行、`Esc` 取消、点遮罩不关闭、按钮可取消/保存。
- 文本为空时保存按钮禁用（避免"清空即删除"误触）；删除任务仍用行内删除按钮。
- 任务行仍最多显示两行；已完成任务同样可双击编辑，行为一致。
- 去掉 `.card` 外层投影，只保留顶部内高光，圆角区域完全透明。

## 非目标

- 不新开独立编辑窗口。
- 弹层里不编辑提醒时间、所属列表（仍用行内按钮）。
- 不改数据模型，不引入富文本。
- 不改窗口宽度、不引入透明边距等窗口几何调整。

## 约束

- 小窗固定 320px 宽、透明无边框，高度由内容驱动、封顶屏幕工作区高度的 45%。
- 渲染层没有测试环境（vitest 只跑 node 环境的纯函数），UI 靠手动运行 + 截图验证。
- 桌上正跑着已安装版 1.2.0，验证时用独立 `--user-data-dir` 的构建版，避免碰真实数据。

## 方案

窗内弹层（遮罩 + 面板）+ 编辑时窗口增高。

考虑过但未采用：

- 独立 `BrowserWindow` 编辑窗：空间更大，但要新增渲染入口、窗口生命周期、保存回传、焦点管理，成本远超收益。
- 行内展开多行文本框：最简单，但不是弹窗，且会推挤列表、跳动明显。

## 实现要点

1. `src/renderer/src/components/TaskRow.tsx`
   - 删除 `editing` / `draft` / `cancelEdit` 与行内 `<input>`；双击文字改为调用 `onEdit(task)`。
   - 提醒、稍后提醒、移动、删除等行内操作保持不变。
2. 新增 `src/renderer/src/components/TaskEditor.tsx`
   - props：`task`、`onSave(text)`、`onCancel()`。
   - 打开时聚焦 textarea，光标置于末尾；高度随内容自适应（1 行起，最多约 12 行后内部滚动）。
   - 键位：`Enter` 保存（阻止默认换行）、`Shift+Enter` 换行、`Esc` 取消；点遮罩不关闭。
   - 保存按钮在 `text.trim()` 为空时禁用；取消按钮与右上角关闭按钮等价。
3. `src/renderer/src/App.tsx`
   - 持有 `editingTask: Task | null`，向 `TaskList` / `LaterSection` 透传 `onEdit`。
   - 渲染弹层（`position: absolute; inset: 0`，铺满 `.card`）。
   - 打开/关闭时同步窗口高度：打开按弹层所需高度调用 `setContentHeight`；关闭后重新测量列表内容恢复原高度。
   - 任务列表里已不存在该 id 时自动关闭弹层。
4. `TaskList.tsx` / `LaterSection.tsx`
   - 增加 `onEdit` 透传。
5. `src/renderer/src/styles.css`
   - `.card` 增加 `position: relative`；`--shadow` 只保留内高光（浅色、深色两套都改）。
   - 新增 `.edit-overlay` / `.edit-panel` / `.edit-textarea` / `.edit-actions` 等样式，沿用现有主题变量。
   - `textarea` 加入通用字体/颜色重置，并允许选中文本。
6. `README.md`
   - 功能列表补一句"双击任务弹层编辑，长文本完整可见"。

## 交互细节（默认决定）

- 点遮罩不关闭，防止误触丢失已输入内容；只有"保存"会写回。
- 窗口隐藏再显示时保留编辑态（隐藏不销毁渲染层）。
- 空文本只在禁用保存上体现，不再从弹层触发删除。
- 保存成功后关闭弹层并恢复高度；保存失败沿用现有提示"保存失败，请重试"，弹层保持打开。

## 验证

- `npm run typecheck`、`npm test`。
- 用隔离 `user-data-dir` 的构建版做截图核对：浅色/深色弹层、长文本滚动、窗口增高与恢复、底部圆角无残影。
- 覆盖：短任务、长任务、已完成任务、编辑中途取消、保存后列表更新。
