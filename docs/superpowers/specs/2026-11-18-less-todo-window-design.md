# less-todo-window 设计文档

日期：2026-11-18
状态：待用户确认

## 背景与意图

目前用便签安排日常任务：任务一多、临时任务插进来就乱，找起来不方便，而且没有任何提醒。

要做的是一个**常驻桌面的置顶小窗**，让今天要做的事一眼可见、随手可记、到点会提醒。它不追求成为一个"完整的任务管理器"，而是把便签的随意感保留下来，同时解决三个具体问题：

1. **乱**：今天的事固定显示在一块，不需要在一堆便签里找。
2. **临时任务没处放**：随手输入即可记下，先放进"以后"，不打断当前工作。
3. **会忘**：设了时间的任务到点弹出 Windows 通知并高亮。

## 目标

- 置顶小窗常驻桌面，随时瞥一眼能看到今天的任务。
- 随手添加：专注输入框，输入文字回车即加入今天。
- 今天 / 以后 两个列表；临时任务默认不进今天，可一键或拖拽移入。
- 任务可设提醒时间；到点系统通知 + 提示音 + 窗口内高亮。
- 勾选完成；未完成的任务第二天自动留在"今天"（像便签不会自己消失）。
- 搜索过滤，快速找到任务。
- 本地保存，重启不丢；关闭窗口后仍常驻托盘，提醒照常生效。

## 非目标

- 云同步、多设备、账户体系。
- 多人协作。
- 项目、标签、优先级、子任务、日历视图、重复任务、附件。
- 手机端。
- 自动更新（v1 手动重新安装升级）。

## 反目标（技术上能做到，但做了就算失败）

- 添加一条任务需要多次点击或鼠标操作。
- 窗口大到挡住正在做的事，或频繁抢焦点、弹模态框。
- 启动慢、内存占用高到影响日常使用。
- 为了"功能完整"而引入项目/标签/优先级等概念，用户不想用。

## 已确认的关键决定

| 决定 | 选择 | 理由 |
|------|------|------|
| 时间模型 | 只有"今天"和"以后"两堆 | 保持便签的随意感，不做排期管理 |
| 窗口形态 | 置顶小窗，固定在屏幕角落 | 需要"抬头就能看见"，不是"用时去找" |
| 提醒方式 | 到点 Windows 通知 + 提示音 + 窗口内高亮；无时间任务不提醒 | 不做打扰式弹窗 |
| 跨天行为 | 未完成的今天任务自动留在今天 | 符合便签心智 |
| 技术栈 | Electron + Vite + React + TypeScript | 本机只装了 Node；需求简单，Electron 最省事 |

## 界面与交互

窗口约 320px 宽，高度随内容自适应（上限约屏幕高度的 45%），无边框圆角卡片，可拖动，位置和大小记忆。默认停靠屏幕右上角。

```
┌────────────────────────────────┐
│  今天 · 5 项        🔍   ⚙  × │
├────────────────────────────────┤
│  ☐  10:00  交周报            🔔 │
│  ☐  回复客户的邮件              │
│  ☐  买牛奶                      │
│  ☑  ~~给妈妈打电话~~            │
├────────────────────────────────┤
│  ▸ 以后 · 3                     │
├────────────────────────────────┤
│  输入任务，回车添加…            │
└────────────────────────────────┘
```

### 添加

- 底部输入框，回车加入**今天**，默认无提醒时间。
- 支持时间前缀：`10:00 交周报`、`10点 交周报` 会自动识别为提醒时间，任务文字只保留"交周报"。识别失败则原文照录，不报错。
- 输入框始终在窗口底部可见，点窗口任意处不抢输入焦点。

### 任务操作

- 单击复选框：完成（划线），短暂停留后移入当天"已完成"折叠区；当天结束清空记录。
- 双击文字：行内编辑；`Enter` 保存，`Esc` 取消，清空文字即删除。
- 悬停出现操作：设/改提醒时间、移到"以后"、删除。
- 排序：今天列表中有提醒时间的按时间升序在前，无时间任务按创建顺序在后；以后列表按创建顺序。

### 以后列表

- 默认折叠为一行"以后 · n"。
- 展开后每条有"→ 今天"按钮，也可直接拖进今天列表。
- 在搜索时，两个列表的匹配结果同时展示（自动展开"以后"）。

### 提醒

- 到点：系统通知（点击通知聚焦并高亮该任务）+ 一声提示音 + 窗口内该任务高亮并置顶。
- 窗口内该任务出现"稍后提醒"按钮（5 分钟 / 10 分钟）。
- 通知在任务被勾选完成或删除后消失；未处理则不重复轰炸，只保留窗口内高亮。
- 系统睡眠期间错过的提醒，唤醒后若未超过 24 小时则立即补发。
- 跨天时，过去时间的提醒自动清除，避免第二天冒出过期通知。

### 搜索与设置

- `Ctrl+F` 或点 🔍 展开搜索框，即时过滤，`Esc` 关闭。
- 设置（⚙ 或托盘菜单）：开机自启、窗口透明度、是否始终置顶。
- 关闭 `×` = 收进系统托盘，应用继续运行；托盘菜单：显示/隐藏、开机自启、退出。

### 外观

- 跟随系统深/浅色；圆角卡片；字体、间距按 Windows 习惯。
- 多显示器断开后，窗口位置自动钳制回可见屏幕内。

## 技术方案

- **Electron**（当前稳定版）+ **electron-vite** + **React 18 + TypeScript**。
- 主进程持有数据与计时器，通过 IPC 与渲染进程通信；渲染进程只负责界面。
- 打包：**electron-builder**，产出 NSIS 安装包与便携版 exe。
- 单实例锁：重复启动时聚焦已有窗口。
- 托盘图标常驻；`app.setLoginItemSettings` 实现开机自启。

### 数据

- 存储在 `%APPDATA%/less-todo-window/data.json`：
  ```ts
  type Task = {
    id: string;
    text: string;
    list: 'today' | 'later';
    createdAt: string;      // ISO
    doneAt: string | null;
    reminderAt: string | null;
  };
  ```
- 设置单独存 `settings.json`（窗口位置/大小/透明度/置顶/自启）。
- 写入用"临时文件 + 原子替换"；每次启动保留最近 3 份备份（`data.json.bak1..3`），读取损坏时回退到最近可用备份并在窗口内提示。
- 数据量级为几百条以内，JSON 足够，不引入数据库。

### 提醒调度

- 主进程维护一个最小堆/定时器集合，最近一条提醒用 `setTimeout`，数据变更时重建。
- 监听 `powerMonitor` 的唤醒事件，重算到期任务并及时补发。
- 应用在托盘常驻，因此关闭窗口不影响提醒。

## 边界情况

- 首次启动：空状态提示"今天还没有任务，在下方输入框写点什么"。
- 任务文字超长：换行最多两行，超出省略；悬停显示全文。
- 删除或完成正在计时的任务：取消定时器。
- 系统时间被调整：重建定时器。
- 同一分钟内多条提醒：合并为一条通知，内容列出任务名。

## 验收标准

1. 添加一条任务全程只用键盘：点进窗口即聚焦输入框，输入后回车出现在今天列表。
2. 关闭窗口后托盘常驻；到点提醒仍能弹出。
3. 重启应用后任务与设置均保持；跨天后未完成任务仍在今天。
4. 提醒触发误差小于 5 秒；点击通知能聚焦窗口并高亮对应任务。
5. 搜索能在今天与以后两个列表中即时找到任务。
6. 数据文件被写坏时能自动回退到备份并提示，不崩溃。

## 留给实现者的

- 具体视觉细节：配色、间距、动画时长（在"圆角卡片、跟随系统主题"的框架内自行决定）。
- 快捷键的进一步优化、无障碍细节。
- 测试策略：核心逻辑（数据读写、跨天结转、提醒调度）用单元测试覆盖；界面用手动验收。
