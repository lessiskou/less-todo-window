# less-todo-window 设计文档

日期：2026-11-18
状态：待用户确认

## 背景与意图

目前用便签安排日常任务：任务一多、临时任务插进来就乱，找起来不方便，而且没有任何提醒。

要做的是一个**常驻桌面的置顶小窗**，让今天要做的事一眼可见、随手可记、到点会提醒。它不追求成为一个"完整的任务管理器"，而是把便签的随意感保留下来，同时解决三个具体问题：

1. **乱**：今天的事固定显示在一块，不需要在一堆便签里找。
2. **临时任务没处放**：随手输入回车即可记下，不打断当前工作；不属于今天的任务再手动收进"以后"。
3. **会忘**：设了时间的任务到点弹出 Windows 通知并高亮。

## 目标

- 置顶小窗常驻桌面，随时瞥一眼能看到今天的任务。
- 随手添加：专注输入框，输入文字回车即加入今天。
- 今天 / 以后 两个列表；"以后"用来收起来不打算今天做的事，可一键或拖拽移回今天。
- 提醒只作用于今天的任务；"以后"里的任务不设提醒，想提醒就先移进今天。
- 任务可设提醒时间；到点系统通知 + 提示音 + 窗口内高亮。
- 勾选完成；未完成的任务第二天自动留在"今天"（像便签不会自己消失）。
- 搜索过滤，快速找到任务。
- 本地保存，重启不丢；关闭窗口后仍常驻托盘，提醒照常生效。

## 非目标

- 云同步、多设备、账户体系。
- 多人协作。
- 项目、标签、优先级、子任务、日历视图、重复任务、附件。
- 手机端。
- 自动更新（v1 手动重新安装升级）。

## 反目标（技术上能做到，但做了就算失败）

- 添加一条任务需要多次点击或鼠标操作。
- 窗口大到挡住正在做的事，或频繁抢焦点、弹模态框。
- 启动慢、内存占用高到影响日常使用。
- 为了"功能完整"而引入项目/标签/优先级等概念，用户不想用。

## 已确认的关键决定

| 决定 | 选择 | 理由 |
|------|------|------|
| 时间模型 | 只有"今天"和"以后"两堆 | 保持便签的随意感，不做排期管理 |
| 窗口形态 | 置顶小窗，固定在屏幕角落 | 需要"抬头就能看见"，不是"用时去找" |
| 提醒方式 | 到点 Windows 通知 + 提示音 + 窗口内高亮；无时间任务不提醒 | 不做打扰式弹窗 |
| 跨天行为 | 未完成的今天任务自动留在今天 | 符合便签心智 |
| 添加去向 | 回车默认加入今天（用户决定） | 记下来不需要任何判断，真正的取舍留给你手动挪 |
| 提醒归属 | 只有今天列表的任务能设提醒；移入"以后"时清除提醒 | "以后"是没日期的停车位，避免看不见的闹钟 |
| 技术栈 | Electron + Vite + React + TypeScript | 本机只装了 Node；需求简单，Electron 最省事 |

## 界面与交互

窗口宽度固定约 320px（不可调整），高度随内容自适应（上限约屏幕高度的 45%，超出滚动），无边框圆角卡片，可拖动，**只记忆位置、不记忆尺寸**。默认停靠屏幕右上角。

```
┌────────────────────────────────┐
│  今天 · 5 项        🔍   ⚙  × │
├────────────────────────────────┤
│  ☐  10:00  交周报            🔔 │
│  ☐  回复客户的邮件              │
│  ☐  买牛奶                      │
│  ☑  ~~给妈妈打电话~~            │
├────────────────────────────────┤
│  ▸ 以后 · 3                     │
├────────────────────────────────┤
│  输入任务，回车添加…            │
└────────────────────────────────┘
```

### 添加

- 底部输入框，回车加入**今天**，默认无提醒时间。
- 支持时间前缀：`10:00 交周报`、`10点 交周报` 会自动识别为提醒时间，任务文字只保留"交周报"。识别失败则原文照录，不报错。
- 时间前缀的日期一律视为**今天（本地时间）**。若该时间已过：按普通任务加入、不设提醒，输入框下给一句轻提示（如"10:00 已过，未设提醒"），不弹窗、不静默。
- 输入框始终在窗口底部可见，点窗口任意处不抢输入焦点。

### 任务操作

- 单击复选框：完成（划线），短暂停留后移入当天"已完成"折叠区；**当天结束（跨天结转时）直接删除已完成任务，不保留历史**。
- 双击文字：行内编辑；`Enter` 保存，`Esc` 取消，清空文字即删除。
- 悬停出现操作：设/改提醒时间、移到"以后"、删除。
- 移到"以后"时若该任务有提醒，一并清除（不给隐藏的闹钟留后路），并在窗口内轻提示一次。
- 排序：今天列表中有提醒时间的按时间升序在前，无时间任务按创建顺序在后；以后列表按创建顺序。

### 以后列表

- 默认折叠为一行"以后 · n"。
- 展开后每条有"→ 今天"按钮，也可直接拖进今天列表。
- "以后"里的任务同样有复选框可以勾选完成，完成的也进入"已完成"折叠区，跨天时一并清空。
- 在搜索时，两个列表的匹配结果同时展示（自动展开"以后"）。

### 提醒

- 到点：系统通知 + 一声提示音 + 窗口内该任务高亮并置顶。
- 同一分钟内多条提醒合并为一条通知，正文列出所有任务名；点击该通知时聚焦窗口并**高亮所有**对应任务。
- 已通知状态记录在任务上（`notifiedAt`）：重启或窗口收进托盘再打开，同一条提醒不会重复弹通知，只恢复窗口内高亮。
- 窗口内该任务出现"稍后提醒"按钮（5 分钟 / 10 分钟）；它直接改写该任务的提醒时间（列表里能看到新时间），重启后仍有效。
- 高亮在以下情况解除：任务完成、删除、修改提醒时间、使用稍后提醒。
- 系统睡眠唤醒：只补发**当天**内已过期的提醒；跨过午夜的过期提醒按跨天规则清除，不补发（跨天结转优先于补发）。
- 跨天时清除所有过去时间的提醒，避免第二天冒出过期通知。

### 搜索与设置

- `Ctrl+F` 或点 🔍 展开搜索框，即时过滤，`Esc` 关闭。
- 设置（⚙ 或托盘菜单）：开机自启、窗口透明度、是否始终置顶。
- 关闭 `×` = 收进系统托盘，应用继续运行；托盘菜单：显示/隐藏、开机自启、退出。

### 外观

- 跟随系统深/浅色；圆角卡片；字体、间距按 Windows 习惯。
- 多显示器断开后，窗口位置自动钳制回可见屏幕内。

## 技术方案

- **Electron**（当前稳定版）+ **electron-vite** + **React 18 + TypeScript**。
- 主进程持有数据与计时器，通过 IPC 与渲染进程通信；渲染进程只负责界面。
- 打包：**electron-builder**，v1 **只出 NSIS 安装包**（不提供便携版）。原因：Windows 系统通知依赖开始菜单快捷方式的 AUMID，开机自启也需要稳定安装路径，便携版无法可靠满足验收标准。
- 单实例锁：重复启动时聚焦已有窗口。
- 托盘图标常驻；`app.setLoginItemSettings` 实现开机自启。

### 数据

- 存储在 `%APPDATA%/less-todo-window/data.json`：
  ```ts
  type Task = {
    id: string;
    text: string;
    list: 'today' | 'later';   // 'later' 的任务 reminderAt 恒为 null
    createdAt: string;         // ISO
    doneAt: string | null;
    reminderAt: string | null; // 只有今天列表的任务可能有值
    notifiedAt: string | null; // 最近一次通知时间，用于防止重复通知
  };
  ```
- 设置单独存 `settings.json`（窗口位置、透明度、置顶、自启；窗口宽度固定，高度自适应，不记忆尺寸）。
- 写入用"临时文件 + 原子替换"；每次启动保留最近 3 份备份（`data.json.bak1..3`），读取损坏时回退到最近可用备份并在窗口内提示。
- 数据量级为几百条以内，JSON 足够，不引入数据库。

### 提醒调度

- 主进程维护一个最小堆/定时器集合，最近一条提醒用 `setTimeout`，数据变更时重建。
- 监听 `powerMonitor` 的唤醒事件，重算到期任务并及时补发。
- 应用在托盘常驻，因此关闭窗口不影响提醒。

## 边界情况

- 首次启动：空状态提示"今天还没有任务，在下方输入框写点什么"。
- 任务文字超长：换行最多两行，超出省略；悬停显示全文。
- 删除或完成正在计时的任务：取消定时器。
- 系统时间被调整：重建定时器。
- 同一分钟内多条提醒：合并为一条通知，内容列出任务名。

## 由实现者自行拿主意的地方（请顺手核对）

评审提出的这些空白，我按以下方式填了，你认为不对可以直接改：

1. **提醒归属**：只有今天的任务能设提醒；移进"以后"时提醒一并清除。
2. **时间前缀**：日期一律按今天解析；时间已过则不设提醒，任务照常加入，输入框下轻提示。
3. **防重复通知**：任务上记录 `notifiedAt`；重启或显示/隐藏窗口后不重复弹同一提醒，只恢复高亮。
4. **稍后提醒**：改写提醒时间本身（5/10 分钟后），重启后仍有效。
5. **睡眠跨午夜**：跨天结转优先，过期提醒清除、不补发；补发只发生在同一天内。
6. **"以后"的任务**：可以勾选完成，完成项进同一"已完成"区；跨天时已完成任务直接删除，不留历史。
7. **合并通知**：点击后高亮这批通知涉及的全部任务。
8. **窗口尺寸**：宽度固定，高度自适应；只记忆位置。
9. **打包**：只提供 NSIS 安装版，不做便携版（通知与自启的可靠性原因）。

## 验收标准

1. 添加一条任务全程只用键盘：点进窗口即聚焦输入框，输入后回车出现在今天列表。
2. 关闭窗口后托盘常驻；到点提醒仍能弹出。
3. 重启应用后任务与设置均保持；跨天后未完成任务仍在今天。
4. 提醒触发误差小于 5 秒；点击通知能聚焦窗口并高亮对应任务；合并通知时高亮其中所有任务；重启应用后同一条提醒不重复弹通知。
5. 搜索能在今天与以后两个列表中即时找到任务。
6. 数据文件被写坏时能自动回退到备份并提示，不崩溃。
