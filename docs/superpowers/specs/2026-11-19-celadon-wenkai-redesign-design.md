# 青瓷 × 霞鹜文楷：小窗视觉改版

日期：2026-11-19
状态：待确认　｜　版本：1.1.0 → 1.2.0

## 意图

现在的界面是"系统默认控件拼起来的样子"：灰白底、蓝色强调、emoji 图标，放在桌面上和很多工具撞脸，也显得单薄。这次只改**视觉与呈现**，让它在桌面角落像一张安静的纸片——有明确的材质、字体性格和层级，但扫一眼仍然清楚今天要做什么。

## 目标

- 保持 320 × 420、置顶小窗、自适应高度：功能、IPC、数据结构、提醒与托盘逻辑全部不动。
- 换成"青瓷"色系：雾青底、松绿强调、圆润控件；浅色 / 深色两套跟随系统。
- 全篇使用**霞鹜文楷 Screen**，字体随应用本地打包，离线可用。
- 用矢量 SVG 图标替换 emoji；补齐悬停、焦点、提醒高亮、空状态。
- 版本号升到 1.2.0，产出新的 NSIS 安装包。

## 非目标 / 反目标

- 不加功能：不做标签、优先级、子任务、统计、云同步。
- 不改窗口位置与尺寸逻辑、不改数据文件格式。
- 不依赖在线字体或 CDN：断网、离线安装都必须正常显示。
- 不为好看牺牲可用性：对比度、键盘焦点、减少动态偏好都要照顾。

## 已确认的选型

| 环节 | 选项 | 结论 |
|------|------|------|
| 视觉方向 | A 纸笺（米纸 / 靛青 / 宋体）、B 夜航（蓝黑 / 黄铜）、C 青瓷（雾青 / 松绿） | **C 青瓷** |
| 字体配法 | 雅黑原样、文楷正文 + 雅黑骨架、全篇文楷 | **全篇文楷** |

三版方向都保留了同样的布局与功能；青瓷最适合常驻桌面、长时间扫读，也最不容易和常见灰白工具混淆。全篇文楷的手写感更完整，用户接受等比数字带来的轻微参差。

## 字体

- **LXGW WenKai Screen**（霞鹜文楷 Screen，屏幕优化版），Regular 400。
- 来源：npm `lxgw-wenkai-screen-webfont@1.7.0`；只引入 GB 版 `lxgwwenkaigbscreen.css`，约 **4.33 MB**（整包 18.8 MB，不引其他字形变体）。
- 在 `main.tsx` 里 `import` 字体 CSS，交给 Vite 打进 `out/renderer/assets`；构建产物连同 asar 一起离线加载。
- 许可证：SIL Open Font License 1.1。把许可文本放进 `resources/`，通过 `extraResources` 随安装包附带，并在 README 注明。
- 字号：正文 **13.5px / 1.55**；标题 **16px / 400 / 0.04em**；时间 11.5px；折叠行 12px；计数 10.5px；提示 11.5px。
- 文楷只有 400：层级靠字号、颜色和留白建立，不用伪粗体。
- 回退：`'LXGW WenKai Screen', 'Microsoft YaHei UI', sans-serif`；`font-display: swap`，字体未就绪时先显示雅黑。
- 数字是比例宽（文楷没有严格等宽），时间列保留固定宽度，接受轻微参差。

## 布局与组件

整体结构不变：可拖动标题栏 → 任务列表 → 已完成 / 以后折叠 → 底部快速添加。改动集中在呈现：

- **标题栏**：`今天` + 胶囊计数；右侧搜索、设置、隐藏三个 24×24 SVG 图标按钮。
- **任务行**：15px 圆角方形复选框（4.5px 圆角）、11.5px 时间列、正文最多两行；悬停时浮出三个 20×20 图标按钮（提醒、移到以后、删除），并带 `title` 与 `aria-label`。
- **以后列表**：展开箭头用 SVG 旋转；任务行用向上的箭头图标移回今天。
- **已完成 / 以后折叠行**：小箭头 + 文案 + 计数，12px 次要色。
- **快速添加**：内凹胶囊输入框 + 松绿圆形加号 + 右侧 `↵` 键帽提示；占位文案"写点什么…"。
- **搜索**：同样的内凹胶囊输入框，放大镜图标，清除与关闭用图标按钮。
- **设置**：三行设置保持原样，滑块与勾选框用松绿强调色；关闭用文字按钮"收起"。
- **提醒高亮**：松绿 12% 底 + 两次数秒脉冲；`prefers-reduced-motion` 下只保留静态底色。
- **空状态**：一行"今天还没有任务，在下面写点什么"，不配插图。
- **滚动条**：细窄、半透明松绿灰，避免默认白槽破坏卡片。

## 交互与无障碍

- 所有可点元素最小 20 × 20（图标按钮），标题栏按钮 24 × 24；保留 `:focus-visible` 的 2px 松绿焦点环。
- 图标按钮必须有 `aria-label`；装饰性 SVG `aria-hidden`。
- 对比度：正文与次要文字按 4.5:1 校验；过期时间只用于加粗提示，也保证可辨。
- 动效统一 120ms ease；高亮脉冲可被系统"减少动态"关闭。
- 原有键盘行为不变：`Ctrl+F` 搜索、`Esc` 关闭、回车添加。

## 技术落点

- 重写 `src/renderer/src/styles.css`：token、组件样式、两套主题。
- 调整渲染层组件标记：`Header`、`TaskRow`、`TaskList`、`LaterSection`、`QuickAdd`、`SearchBar`、`SettingsMenu`——只换图标与结构类名，不改 props 与回调。
- `App.tsx` 的外观不变，必要时只补类名。
- `main.tsx` 引入字体 CSS；`package.json` 增加字体依赖并把版本升到 1.2.0。
- 不改 `main/`、`preload/`、`shared/` 下任何逻辑；测试全部保持。
- `electron-builder.yml` 增加字体许可文件的 `extraResources`。

## 风险

- **体积**：字体 +4.3MB，安装包变大；换取离线与统一字形，可接受。若嫌大，后续可改成"检测到本机已装文楷则用系统字体"，但首版直接内置。
- **首屏闪烁**：`font-display: swap` 会先显示雅黑再换字，持续时间取决于本地字体加载；如明显，再考虑预加载关键子集。
- **深色是新设计**：青瓷的深色版是这次新绘制的，需截图确认对比度和气质。
- **比例数字**：时间列会有轻微参差，已由用户确认接受。
